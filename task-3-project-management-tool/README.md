# Task 3 - Project Management Tool

A collaborative Trello/Asana-style project management tool.

## Features
- Authentication
- Create projects
- Project boards
- Create task cards
- Assign tasks to project members
- Move tasks between Todo / In Progress / Done
- Task details
- Comments inside tasks
- Add/remove project members
- User list
- Database for users, projects, tasks and comments
- WebSocket real-time project updates (bonus)

## Run
```bash
npm install
npm start
```
Open http://localhost:3000
