# Task 2 - Mini Social Media Platform

Full-stack mini social media app built with HTML, CSS, JavaScript, Node.js and Express.js.

## Features
- User registration/login/logout
- User profiles
- Edit profile
- Create posts
- Posts feed
- Comments
- Like/unlike posts
- Follow/unfollow users
- Followers/following counts
- User search
- Database for users, posts, comments, followers and likes
- Responsive UI

## Run
```bash
npm install
npm start
```
Open http://localhost:3000
